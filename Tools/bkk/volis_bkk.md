## Bash Kennel Master (BKK)

The estate's launch discipline: the properties every door that builds, launches
or tests a managed subprogram must satisfy — uniform conditions, an honest
answer to whether the artifact is current, and bounded reporting that never
lies — whatever language produced the artifact and whatever language the door
is written in.

The kit stands on the bash substrate, which the leading letter of its name
records: every door is a tabtarget, every declaration a bash-readable regime
file, and the bootstrap is bash on the station's tackroom, whatever the kit's
interior is written in. Language backends are tenants inside the discipline
rather than the discipline itself; rust stands at MVP and python beside it.

### The doors

Every door is a tabtarget — **one tabtarget per door, never one per collar** —
and a call is three things in order: the verb, which is the tabtarget's
colophon and frontispiece; the collar, which is the door's first argument; and
after the collar, what the collar's kind owns. No flag rides the shape. The
verbosity dial is the substrate's own `BURE_VERBOSE`, so the output-flavor axis
needs no flag.

| door | takes | does |
|------|-------|------|
| **mush** | a collar, then what its kind owns | the launch seam: muzzle the suite, then run the selection pipeline; an app execs its elected binary |
| **derby** | nothing | every suite collar the walk finds, stopping at the first red course |
| **heel** | a collar | converge — build current through the leash and install at the residence |
| **lineup** | a collar | the no-run listing of a suite's hurdles |
| **tattoo** | a collar | the read-only examination: proclamation, findings, election verdict |
| **muzzle** | nothing | lint every collar in the walk at its declared muzzle directory |
| **gangline** | a collar | re-derive one collar's lock, with the lock flag lifted |
| **scoop** | nothing | the whole yard's clean, on the operator's word alone |

Two tabtargets stand in `tt/` and are **not** doors of this register: the
**whistle**, which is the bootstrap and is bash, and the **kennelman**, which
runs the kennel's own suite when the kennel cannot. The tabtarget listing is
the whole registry — a door's Rust file wears its tabtarget letter, so `ls tt/`
answers what the kennel can be asked to do.

### Vocabulary

| term | meaning |
|------|---------|
| **collar** | the per-launchable declaration — one instance per launchable, naming it and saying whose it is |
| **leash** | the chokepoint every toolchain invocation passes through: the pin stated, the lock flag on every call, the tackroom fence |
| **whistle** | the thin bash bootstrap that builds the kennel binary and execs a door |
| **hurdle** | one test case — a launch carrying an expectation, at the grain of the single case |
| **course** | a suite — the set of hurdles one collar launches as one unit |
| **delouse** | the periodic sweep that throws build caches away, fired from inside derby and heel |
| **kibble** | a program the kennel spawns and did not build: a pin over foreign source or a foreign release |
| **lure** | a composed seat the kennel is driven over for one hurdle |
| **tamed** / **feral** | a crate whose build script fetches during compilation is *feral* and is barred, never served |

### Discipline

- **Nothing a door writes stands in the tracked tree**, so no door's own output
  can trip the door law that refuses an uncommitted repository. A measurement of
  the tree is a fact file; a door's working memory stands in the seat's own
  scratch.
- **Currency is git position**, carried on the artifact by the exergue pattern:
  an artifact carries the source position it was struck from, and a reader
  compares positions.
- **A door is bounded by the tree it entered.** It proves what that one tree can
  prove about itself and learns nothing of the kraal the tree stands in.
- **No platform name enters the kennel** — not its source, its collars, its
  regime files or its hurdles. What differs between hosts is met by a tool's
  presence or by a declared fact.
- **In a dispatched session, drive a kennel test door through the engine's own
  tabtarget door**, never by bash: a door run by bash is a run the engine never
  sees, so what it measured is discarded rather than recorded.

### Acronym Notes

Annotations for the acronym homes of the Bash Kennel Master corpus — the
per-row descriptions and family topology a bare index does not carry. The codex
is a shell that owns the vocabulary, the premises and the branch list; every
detail lives in the branch that binds it, and standing is declared per branch at
its inclusion point.

| Acronym | File | Description |
|---------|------|-------------|
| **BKS0** | `specs/bkk/BKS0-BashKennelMasterSpec.adoc` | Bash Kennel Master Specification — the codex: the mapping section every branch consumes, the three premises (platform-blind, tree-bounded, tamed-build), and the branch list. Holds no detail of its own. |
| **BKSNC** | `specs/bkk/BKSNC-Kennelcraft.adoc` | Kennelcraft — the founding branch: the language-neutral discipline and its six properties, the frozen command surface and its eight doors, currency by git position, the delouse ceremony, the rust backend with its measured invocations and the feral class, the crate audit, and the binary election. Mints `bksnc_`. |
| **BKSOB** | `specs/bkk/BKSOB-Obedience.adoc` | Obedience — the test dialect: what a case speaks inside a launch, the error-if op family with fatal-if on panic, precept and rivet citation, the trace, and the declared costs and spend. A vanilla test under the standing runner stays a full citizen of every door. |
| **BKSCL** | `specs/bkk/BKSCL-Collar.adoc` | Collar — the declaration regime: one instance per launchable, distributed through the trees it declares, per-language families rendering one uniform proclamation. The identity law, the source-identification triplet, the tamed and feral crate lists, and the door law that reports and refuses. Mints `bkscl_`. |
| **BKSMZ** | `specs/bkk/BKSMZ-Muzzle.adoc` | Muzzle — the build-time refusals a door carries: which calls each bars, the sentence each states to the author who trips it, and how far it reaches. Keeps no record and has no age. Mints `bksmz_`. |
| **BKSLR** | `specs/bkk/BKSLR-Lure.adoc` | Lure — how the kennel proves itself: the composed seat its own hurdles run over, the kennelman that runs them when the kennel cannot, the toolchains the station must hold, and the two drives a hurdle makes. Mints `bkslr_`. |
| **BKSBL** | `specs/bkk/BKSBL-Kibble.adoc` | Kibble — the declaration regime for a program the kennel spawns and did not build: a pin over foreign source or a foreign release, never a launchable. The two kinds with their first consumers, the seal that answers for it, and the residence it stands in once proven. |
| **BKSPY** | `specs/bkk/BKSPY-Python.adoc` | Python — the tenant: the three-layer chain that makes an environment reproducible, the two halves of the store it stands in, the settings the kennel states to uv, and the validation it runs over a project's own declaration files. The venv law homes here, the substrate's own python sheaf standing as a pointer to it. |
| **BKSCB** | `specs/bkk/BKSCB-chapbook_kennel.adoc` | Chapbook — the stitched happy-path tale: the cast that acts, the kennel's critical sequences in order, and every interaction citing the contract that governs it. Its pending-citation register is the canon's convergence gauge. |

Every branch of the codex stands executory: binding as design — cite it and
build to it; the work product does not yet enact it. Four of the eight mint a
category; the other four declare none, because a concept earns a quoin when a
consumer must refer to it across a boundary and none of theirs is yet referred
to across one.
