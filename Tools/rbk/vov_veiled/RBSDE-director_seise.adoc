//axhob_operation
{rbtgo_director_seise}

NOTE: This operation writes `RBRR_SUBSTRATE_RELIQUARY=«TOUCHMARK»` into the one {rbrr_regime} file, electing the reliquary {rbtga_lode} the vessel-less substrate captures ({rbtgo_lode_underpin}, {rbtgo_lode_immure}) resolve their build tools from.
The made side and bole carry a per-vessel {rbrv_reliquary}; the substrate captures load no vessel, so the repo regime elects one reliquary for them here.
Seise is a {rbch_enchase} on the {rbf_fact_lode} touchmark chain conclave hands forward — the substrate-branch sibling of {rbtgo_director_yoke}.
The ceremony is conclave → seise → commit → capture: a reliquary {rbtgo_lode_conclave} captures the tool cohort and hands its touchmark forward; seise elects it into the repo regime (or from an express touchmark); the operator commits; a substrate capture then resolves its pinned tools from the committed election.

NOTE: *No GAR call, no clean-tree gate, no fact.*
Seise resolves the election purely from the touchmark and its kind-letter prefix — it makes no {gar_service} call.
Cohort completeness is validated where it is consumed: a substrate capture build pulls each tool member from the elected reliquary and fails loud on a missing one, exactly as {rbtgo_ark_conjure}'s registry preflight backstops {rbtgo_director_feoff}.
It does not gate on a clean tree (rivet RBr_a52), and it emits no chaining fact of its own: a {rbch_enchase} relays-then-reads, forwarding the baton before electing so the fact stays live for a following chain verb or a retry (rivet RBr_3e7).
This primitive does not commit; the operator commits the {rbrr_regime} change.

NOTE: *Loud on success.*
On a successful write seise emits the elected touchmark and its source — an express argument versus the chained capture — so a wrong election shows at the moment of action rather than only in the eventual git diff.

//axhos_step
. *Rewrite the {rbrr_regime}*:
.. Substitute the `RBRR_SUBSTRATE_RELIQUARY=` line with `RBRR_SUBSTRATE_RELIQUARY=«TOUCHMARK»`, preserving position; if no such line is present, append one
.. All other lines pass through unchanged
.. Write the composed content to a temp file, then atomically replace the {rbrr_regime} file via rename
.. {rbbc_fatal}
on any I/O failure

//axhoc_completion
Successful execution writes `RBRR_SUBSTRATE_RELIQUARY=«TOUCHMARK»` into the {rbrr_regime} file; no GAR state is read or modified, and no chaining fact is emitted.
The primitive does not commit — the operator commits the modified {rbrr_regime} file with their usual git workflow, after which a substrate capture resolves its pinned build tools from the committed election.
A reliquary {rbtgo_lode_conclave} recaptured under a fresh touchmark is picked up by re-running seise and re-committing.
