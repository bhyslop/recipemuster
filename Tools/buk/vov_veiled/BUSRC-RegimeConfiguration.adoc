{burc_regime}

BURC is the project-repo configuration regime:
the fixed, per-repository shape — station-file pointer, tabtarget infrastructure, project directory layout, per-dispatch output placement, log-file naming —
that every tabtarget composes from before dispatch can locate its own tools.
Values arrive by
{bus_inlet_assignment}
from a single
`.buk/burc.env`
per repository,
the file-sourced pattern BURC shares with
{burs_regime},
{burn_regime},
and
{burp_regime}.
