{burn_regime}

This regime describes the shape of a remote target — host and
platform — shared across every station user by git and changed
rarely.
Its values arrive by
{bus_inlet_assignment}:
a burn.env sourced from
`.buk/rbmn_nodes/<{burn_investiture}>/burn.env`.
A
{burn_regime}
instance is identified by its
{burn_investiture}
(directory name) and carries no key material, credentials being
{burp_regime}'s
separate, per-station-user concern.
{burn_regime}
is the sole home of a node's address-of-record, per
{burn_host_singularity}:
a
{burp_regime}
instance locates its node by nothing more than directory-name equality
between its own
{burp_investiture}
and a registered
{burn_investiture},
enforced by file-presence check at load time — no field in either
regime carries the cross-reference.
