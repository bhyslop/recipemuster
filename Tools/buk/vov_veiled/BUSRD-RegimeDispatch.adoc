//axhrb_regime
{burd_regime}

This regime is the ephemeral runtime state
bud_dispatch.sh
assembles during tabtarget execution.
Unlike the file-sourced regimes, BURD has no
{axrg_assignment}
file — the dispatch main function itself is its
{bukro_kindle}:
zbud_setup sources configuration and derives computed state, and zbud_process_args parses the tabtarget into tokens.
Its values arrive by two inlets, declared per group:
{bus_inlet_tabtarget}
for the input group,
{bus_inlet_derived}
for the computed and parsed groups.
Never
{bus_inlet_ambient}:
a `BURD_*` value observed by inheritance rather than installed by the dispatch chain is contraband
({BUr_q2m}).

//axhrgb_group
{burd_group_input}

Variables installed by the committed dispatch chain itself, ahead of
bud_dispatch
({bus_inlet_tabtarget}).
The tabtarget's own `BURD_*` block installs its identity —
{burd_launcher}
and the mode flags
{burd_no_log}
and
{burd_interactive} —
and the launcher scripts it execs install the rest.
Never set from the ambient environment
({BUr_q2m}).

//axhrgv_variable
{burd_no_log}

When non-empty: no log files are created, the launcher skips the
{burs_regime}
station load (a no-log tabtarget must run on a fresh clone before any station file exists), and the coordinator's streams pass through unmerged.
Two tabtarget populations carry it: handbook and regime tabtargets that must run pre-station, and interactive doors that hand the terminal to a program that cannot run under the log tee.
The suppression belongs to the door's own dispatch alone — a session or child the door launches takes its dispatch modes from its own
{bus_inlet_s}.

//axhro_kindle
{bukro_kindle}

Inline within zbud_main — no separate kindle function.
zbud_setup sources the regime file, derives computed variables, and creates ephemeral directories; zbud_process_args parses the tabtarget and sets parsed variables.

//axhro_validate
{bukro_validate}

Runs a compgen scan after all variables are set and dies on any `BURD_*` variable outside the known roster — the mechanical edge of the inlet law: a stray inherited or hand-exported `BURD_*` name fails loud
({BUr_q2m}).
A sentinel (zburd_sentinel) lets downstream code assert dispatch is properly initialized.
