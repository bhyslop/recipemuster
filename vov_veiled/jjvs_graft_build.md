# Push an Image Built on This Machine Into Your Depot

## The walk

### Goal

An image from this machine's Docker stands in your depot as a Graft, as the director's graft track teaches it: the image the track names stands pulled into this machine's Docker and tagged under the local name the track gives it; the settings of the graft Vessel name that local tag; the Ordain the track gives has pushed the image to the depot as a Hallmark and recorded its verdict; and you have vouched and tallied as the track directs, and read the verdict it reports.

The documents to take up, in this order: the `README.md` at the root of the clone; the onboarding guide it tells you to run; and, from that guide's start menu, the director track "Local Image Publishing", with what the start menu says of every director track.
Walk that track from its first line to its closing section, "What you learned", and stop there.
Other documents stand in the clone — the other tracks, the guides other commands print, and the project's code and configuration files beyond those a direction names — and are left unopened, as a newcomer might not think to open them.

The ground this walk stands on: the first-cloud-build walk on this same clone left what this track assumes: the depot it built in, the attendant's own user wearing the director and retriever Mantles in it, the build tools' Lode captured and its Touchmark written into the settings of every Vessel, the graft Vessel among them, and every change committed.
Other walks may have run on this clone, and this walk uses nothing they left.
`RBRV_GRAFT_IMAGE` in the settings of the graft Vessel stands blank, as the clone shipped it.
Docker stands installed and running on this machine, and can pull from Docker Hub.
The first-cloud-build walk's Sederunt may have lapsed since: before your first act run `tt/rbw-as.EspySederunt.sh` and report what it shows, then open a fresh Sederunt by the Novate door the first-cloud-build track gives, `tt/rbw-aN.NovateSederunt.sh`, before the track's first step.
Where an Ordain warns that the depot's build quota is short, report the warning and walk on as the build does: asking for more quota is no act of this walk.

### Acts reserved to the attendant

Reserved to the attendant, in a browser of their own, proving identity: when the Novate door you run prints a sign-in address and a code, the attendant opens that address, enters the code, and signs in as their own user, the one wearing the director and retriever Mantles in this depot.
