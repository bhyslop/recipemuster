# Build Your First Image in the Cloud

## The walk

### Goal

Your first image has been built in the cloud, inspected, pulled to this machine and taken back down, as the director's first-build track teaches it: the attendant's own user wears the director and retriever Mantles in this clone's depot; the build tools' Lode stands in the depot, captured by the Conclave, and its Touchmark stands written into every vessel's settings and committed; a Hallmark of the track's Sentry vessel was built by the Ordain the track gives, inspected by the doors the track names, and pulled into this machine's Docker by the Summon; and that Hallmark has since been removed from the depot by the Abjure, as the track's last steps direct.

The documents to take up, in this order: the `README.md` at the root of the clone; the onboarding guide it tells you to run; and, from that guide's start menu, the director track "Your First Cloud Build", with what the start menu says every director track requires before its first step.
Walk that track from its first line to its last step, "The pattern", and stop there.
Other documents stand in the clone — the other tracks, the guides other commands print, and the project's code and configuration files beyond those a direction names — and are left unopened, as a newcomer might not think to open them.

The ground this walk stands on: the depot walk on this same clone left a depot levied under the cloud prefix the clone's depot settings name, the attendant's own user seated as its first governor by the Gird and holding no other Mantle in it, and every setting it filled committed.
That walk's Sederunt may have lapsed since, so before your first act run `tt/rbw-as.EspySederunt.sh` and report what it shows: it signs no one in and changes nothing.
What the start menu requires of a director track is met, for this walk, by the two Brevets reserved below, made once the track's sign-in stands and before its first step.
Each admits the attendant's own user, whose subject is the one `tt/rbw-pr.GovernorRehearsesTerrier.sh` shows holding the governor Mantle in this depot; read it there yourself.
Where an Ordain warns that the depot's build quota is short, report the warning and walk on as the build does: asking for more quota is no act of this walk.

Reserved to the attendant at the terminal, granting access — admitting their own user onto the retriever Mantle: the same door, naming the same subject and then `retriever`.
